Desktop browser required

This map generator is not available on mobile browsers.

Tool controls

Sea level mode

Sets the elevation that will be zero in the heightmap, everything below is cut off.

Absolute
Enter the meters directly
Relative
Enter the percentile which shall be used as the cutoff elevation. Useful for maps around lakes
Auto
The tool will calculate the cutoff elevation on its own

Town granularity levels

Depending on zoom level, the finer granularities are unavailable.

Off
Only a heightmap.png file will be generated
1
Only large cities will be counted
2
Level 1 plus large towns
3
Level 2 plus villages and suburbs

Usage in OpenTTD

The heightmap can be loaded on its own, via "Play Heightmap".

In the scenario editor, the heightmap can be loaded (save icon menu), alongside the towns.json file, under the towns menu -> "Generate towns" -> "Load from file".

Generating random industries recommended.

About this project

This project is being run by me on my own, as the developer and hoster. The source code, alongside more thorough documentation, can be obtained on my GitHub.

Planned features

  • Choosing a point on the map, to use its elevation as sea level cutoff point
  • Resizing of the viewport, to generate non-square rectangular maps
  • Advanced settings (e.g. normalization parameters and non-latin-alphabet town name handling)
